# Forge Habit Tracker — Smoke Suite

## Load the app
Open http://localhost:3000.
Verify the page title or heading contains "Forge".
Verify the text "Daily habits" or "Start your first habit" is visible.

## Open the add form
Click the button or area that says "Add a habit".
Verify an input field for the habit name appears.

## Create a habit
Type "Morning run" into the habit name input.
Click the "Create habit" button.
Verify a habit card with the text "Morning run" is now visible on the page.

## Mark complete
Click the check / complete button on the "Morning run" habit card.
Verify the habit shows as completed (check mark or completed styling is visible).

## Toggle theme
Click the theme toggle button (moon or sun icon).
Verify the page background or theme changes (dark class or different colors appear).
